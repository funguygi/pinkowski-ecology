We build rooms.

We build systems.

We build experiences.

Code is the implementation of architecture.

# Development Rules

Before writing code ask:

Does this support the Design Bible?

Does this support the Architecture Specification?

Does this support The Story?

Would a visiting scientist believe this belongs here?

If not—

Redesign.

---

# Success Criteria

Field Station succeeds when visitors forget they are browsing a website.

Instead they believe they have arrived somewhere.

A place where curiosity is welcomed.

Where science is beautiful.

Where careful observation changes how people see the natural world.

Every completed sprint should make the institution feel older, richer, quieter, and more alive.
